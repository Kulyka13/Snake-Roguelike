### 1. Структура каталогу проєкту (Unity)

Файлова структура репозиторію **Snake-Roguelike** організована за компонентною архітектурою Unity, де скрипти, конфігурації модифікаторів, префаби, сцени, тайли та графічні ресурси розділені по відповідних директоріях:

    Snake-Roguelike/
    ├── Assets/
    │   ├── Modifiers/                 # Асети конфігурацій модифікаторів (ScriptableObjects)
    │   ├── Prefabs/                   # Готові шаблони ігрових об'єктів
    │   │   ├── Food.prefab            # Префаб базового яблука
    │   │   ├── ModifierCanvas.prefab  # Префаб UI-панелі вибору модифікаторів
    │   │   ├── MutagenFood.prefab     # Префаб мутагенної їжі
    │   │   └── SegmentPrefab.prefab   # Префаб сегмента тіла змійки
    │   ├── Scenes/                    # Ігрові сцени проєкту
    │   │   └── SampleScene.unity      # Основна ігрова сцена
    │   ├── Scripts/                   # Вихідний код гри на C#
    │   │   ├── ArenaSpawner.cs        # Генератор об'єктів на ігровому полі
    │   │   ├── BonusApple.cs          # Логіка бонусних яблук
    │   │   ├── Food.cs                # Базова логіка їжі та позиціонування
    │   │   ├── ModifierSelectionUI.cs # Керування інтерфейсом вибору модифікаторів
    │   │   ├── MutagenFood.cs         # Механіка мутагенної їжі (активація вибору бафів)
    │   │   ├── PathPoint.cs           # Структура точок траєкторії руху
    │   │   ├── PortalApplePair.cs     # Механіка парних порталів на арені
    │   │   ├── SnakeBody.cs           # Керування сегментами тіла та хвостом змійки
    │   │   ├── SnakeEffectsManager.cs # Менеджер активних ефектів та модифікаторів
    │   │   ├── SnakeModifier.cs       # Модель даних та параметри окремого модифікатора
    │   │   ├── SnakeMovement.cs       # Головний контролер сіткового руху, вводу та колізій
    │   │   ├── SnakeSegment.cs        # Компонент окремого сегмента хвоста
    │   │   ├── SpriteFadeIn.cs        # Візуальний ефект плавної появи об'єктів
    │   │   └── SpriteFadeOut.cs       # Візуальний ефект плавного зникнення об'єктів
    │   ├── Settings/                  # Налаштування рендеру та Unity Input System
    │   ├── Sprites/                   # 2D-графіка та візуальні ресурси
    │   │   ├── Anton/                 # Спрайти голови, тіла та візуальних станів персонажа
    │   │   ├── Apples/                # Спрайти їжі та інтерактивних об'єктів (яблука, баклажан, портали)
    │   │   └── Tiles/                 # Тайли фону та декору ігрового поля (трава, квіти)
    │   ├── TextMesh Pro/              # Ресурси та шрифти для рендерингу тексту в UI
    │   └── Tilemap/                   # Палітри та асети тайлової карти арени
    ├── Packages/                      # Залежності та пакети проєкту Unity
    ├── ProjectSettings/               # Системні налаштування рушія
    ├── .gitignore                     # Фільтрація тимчасових файлів Unity (Library, Temp, білди)
    └── README.md                      # Опис репозиторію

### 2. Розподіл функціональності за модулями та їх відповідальність

Архітектура проєкту побудована за компонентним принципом (Component-Based Architecture) і поділяється на п'ять логічних модулів:

1. **Ядро руху та тіла змійки (`SnakeMovement`, `SnakeBody`, `SnakeSegment`, `PathPoint`):**
   * *Відповідальність:* дискретне переміщення голови по цілочисельній сітці за таймером, зчитування команд керування (New Input System), запис історії траєкторії (`PathPoint`), інтерполяція позицій сегментів хвоста (`SnakeBody`, `SnakeSegment`) та перевірка зіткнень.

2. **Генерація та інтерактивні об'єкти арени (`ArenaSpawner`, `Food`, `BonusApple`, `MutagenFood`, `PortalApplePair`):**
   * *Відповідальність:* контроль вільних клітинок на полі, спавн базових (`Food`), бонусних (`BonusApple`) і мутагенних (`MutagenFood`) об'єктів, а також робота парних телепортів (`PortalApplePair`).

3. **Система модифікаторів та ефектів (`SnakeModifier`, `SnakeEffectsManager` + асети з `Assets/Modifiers/`):**
   * *Відповідальність:* зберігання конфігурацій здібностей у вигляді асетів, активація тимчасових або пасивних ефектів (щити, уповільнення часу, вибухи яблук, ривок) та відстеження їх тривалості під час забігу.

4. **Інтерфейс користувача (`ModifierSelectionUI`, `ModifierCanvas.prefab`, `TextMesh Pro`):**
   * *Відповідальність:* відображення панелі вибору roguelite-модифікаторів при поглинанні мутагенної їжі, передача обраної здібності до `SnakeEffectsManager` та оновлення ігрового HUD.

5. **Візуальні ефекти та оточення (`SpriteFadeIn`, `SpriteFadeOut`, `Tilemap`):**
   * *Відповідальність:* плавна зміна прозорості (альфа-каналу) спрайтів під час спавну нових об'єктів на полі й зникнення сегментів або бонусів, а також візуальна побудова арени через `Tilemap`.

### 4. Обґрунтування прийнятих архітектурних рішень

1. **Декомпозиція руху та керування хвостом (`SnakeMovement` + `SnakeBody`):**
   Винесення логіки сегментів хвоста у `SnakeBody` та `SnakeSegment` розвантажило головний скрипт `SnakeMovement`, спростивши підтримку коду та додавання механік на кшталт втрати чи відновлення сегментів.

2. **Централізований спавнер арени (`ArenaSpawner`):**
   Замість того щоб кожен тип яблука чи порталу самостійно шукав вільне місце на карті, `ArenaSpawner` координує появу `Food`, `BonusApple`, `MutagenFood` та `PortalApplePair`, запобігаючи накладанню об'єктів один на одного.

3. **Data-driven підхід для модифікаторів (`Assets/Modifiers/` + `SnakeModifier`):**
   Конфігурації модифікаторів винесені в окремі асети (`ScriptableObject`), а їх виконанням керує `SnakeEffectsManager`. Це дозволяє балансувати параметри та додавати нові здібності без зміни базової логіки змійки.

4. **Ізольовані компоненти візуальних переходів (`SpriteFadeIn`, `SpriteFadeOut`):**
   Анімація прозорості оформлена як незалежні компоненти, які можна прикріпити до будь-якого префаба (`Food`, сегментів чи порталів) без дублювання коду таймерів у геймплейних скриптах.
