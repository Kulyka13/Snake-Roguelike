# Практична робота №9
**Тема:** Основи Git та GitHub
**Результат:** Налаштований GitHub-репозиторій

---

### 1. Створення репозиторію та налаштування
* Створено репозиторій **Snake-Roguelite** через **GitHub Desktop**.
* Під час ініціалізації додано **`.gitignore` (шаблон Unity)** — для автоматичного ігнорування системних файлів і кешу рушія (`Library/`, `Temp/`, білдів).
* Виконано початкову публікацію проєкту на GitHub (`Publish repository`).

---

### 2. Робота зі змінами
* **Changes:** відстеження нових файлів документації та скриптів у робочій директорії.
* **Commit to main:** фіксація внесених змін із коротким описом виконаної роботи.
* **Push origin:** відправка локальних комітів на віддалений репозиторій GitHub.
* **History:** перегляд історії комітів та списку змінених файлів у відповідній вкладці клієнта.

---

### 3. Висновок
Опановано базовий робочий процес Git у GitHub Desktop: створення й публікацію репозиторію, налаштування `.gitignore`, створення комітів (commit), синхронізацію з віддаленим сервером (push) та навігацію історією змін.
