# 🐍 Snake-Roguelike

2D-аркада з елементами **roguelite**, розроблена на рушії **Unity 6** (C#). Класична механіка змійки поєднана із системою випадкових мутацій, порталами, ривками та прогресією рахунку.

> Проєкт розроблено командою **Placeholder** у межах навчального курсу з інженерії програмного забезпечення (ЛНТУ).

---

## 🎮 Основні можливості

* **Плавний рух по сітці та телепортація крізь межі арени** (screen wrapping).
* **Різноманітні об'єкти на арені:**
  * 🍎 **Звичайне та бонусне яблука** — збільшують довжину змійки та додають очки.
  * 🤢 **Гниле яблуко** — зменшує довжину або завдає шкоди.
  * 🌀 **Яблука-портали** — миттєво переносять змійку в іншу точку арени та нараховують додаткові очки.
  * 🧬 **Мутаген** — зупиняє час і відкриває меню вибору одного з випадкових модифікаторів.
* **Система roguelite-модифікаторів:**
  * *Привид* — дозволяє тимчасово проходити крізь власний хвіст.
  * *Фазовий ривок* — миттєве прискорення на кілька клітинок (`Space` / `Left Shift`) із невразливістю під час ривка.
  * *Броньований панцир* — поглинає одне смертельне зіткнення.
  * *Уроборос* — при зіткненні з хвостом змійка відкушує частину сегментів замість загибелі.
  * *Інверсія* — тимчасово інвертує керування вліво/вправо та змінює вигляд голови.
  * *Холоднокровність / Сповільнення часу* — уповільнює темп гри або рух під час поворотів.
  * *Скидання шкіри / Реверс / Яблучний вибух* — додаткові тактичні ефекти зміни довжини, напрямку руху та спавну їжі.
* **Повноцінний ігровий цикл:** головне меню (`MainMenu`), система збереження рекордів (`PlayerPrefs`), меню паузи (`Esc`), екран завершення забігу та миттєвий рестарт (`R`).

## 🚀 Встановлення та запуск

### Варіант 1: Запуск готової збірки (для гравців)
1. Перейдіть у розділ **[Releases](https://github.com/Kulyka13/Snake-Roguelike/releases)** репозиторію та завантажте актуальний архів (`Snake-Roguelike-Win64.zip`).
2. Розпакуйте архів у будь-яку зручну папку.
3. Запустіть файл **`Snake.exe`**.

### Варіант 2: Запуск із вихідного коду в Unity (для розробників)
1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Kulyka13/Snake-Roguelike
   ```
2. Відкрийте **Unity Hub**, натисніть **Add → Add project from disk** та виберіть папку `Snake-Roguelike`.
3. Відкрийте проєкт у **Unity 6 (`6000.6.6f1` або новішій версії)**.
4. У вікні `Project` відкрийте сцену `Assets/Scenes/MainMenu.unity` та натисніть кнопку **Play** у верхній панелі редактора.
